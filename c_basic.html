Module 01

Introduction to C Programming

C is a general-purpose, procedural programming language developed in 1972 by Dennis Ritchie at AT&T Bell Laboratories. Originally designed to rewrite the UNIX operating system, C provides direct control over computer memory and hardware while maintaining a structured, readable syntax.

Analogy — The Foundation of Modern Software:
Learning C is like learning to drive a manual transmission car. It teaches you how the engine, clutch, and gears actually interact. Understanding C provides a solid foundation for mastering memory management, operating systems, and other programming languages.

Where is C Used Today?

C powers operating systems (Linux, Windows, macOS kernels), embedded systems (microcontrollers, automotive computers, IoT devices), and game engines where execution speed and minimal memory overhead are essential.

Module 02

Structure of a C Program

Every C program follows a precise blueprint. Let's inspect the universal first program:

hello.c 
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
Terminal Output:
Hello, World!

Line-by-Line Breakdown:

  • #include <stdio.h>: Standard I/O header containing the definition for printf().
  • int main(): The mandatory entry point where computer execution begins.
  • { ... }: Curly braces define the boundaries of the code block.
  • printf(...): Built-in function that prints text to the screen.
  • ; (Semicolon): Marks the end of an executable statement in C.
  • return 0;: Signals to the operating system that the program completed successfully without errors.
Module 03

Variables, Constants & Data Types

A variable is a named storage location in memory whose value can change during program execution. A constant is a value defined once that remains fixed.

Data Type Keyword Typical Size Format Specifier Example Value
Integerint4 bytes%d42
Single Floating Pointfloat4 bytes%f3.14f
Double Precisiondouble8 bytes%lf3.14159265
Single Characterchar1 byte%c'A'
variables_demo.c 
#include <stdio.h>

int main() {
    int studentAge = 19;
    float cgpa = 8.75;
    char grade = 'A';
    const int passMark = 35;

    printf("Age: %d | CGPA: %.2f | Grade: %c | Pass: %d\n", 
           studentAge, cgpa, grade, passMark);
    return 0;
}
Terminal Output:
Age: 19 | CGPA: 8.75 | Grade: A | Pass: 35
Module 04

Input and Output: printf() & scanf()

Input and output allow your program to communicate with the user. printf() sends information out to the screen, while scanf() reads data typed into the keyboard.

Why is the & (Ampersand) Required in scanf()?
Think of a variable as a labeled locker. When asking someone to deliver mail into your locker, you don't give them the value inside—you give them the address of the locker. The & operator provides the memory address so scanf() knows exactly where to store the user's input.
input_demo.c 
#include <stdio.h>

int main() {
    int age;
    printf("Enter your age: ");
    scanf("%d", &age);

    printf("You entered age: %d\n", age);
    return 0;
}
Simulated Interaction:
Enter your age: 19 You entered age: 19
Module 05

Operators in C

Operators are special symbols that instruct the compiler to perform specific mathematical, logical, or relational operations.

1. Arithmetic Operators (Math)

Perform basic mathematical operations on numbers.

OperatorMeaningSimple ExampleResult
+Addition10 + 313
-Subtraction10 - 37
*Multiplication10 * 330
/Division (Quotient)10 / 33 (integer drops decimal)
%Modulus (Remainder)10 % 31 (leftover remainder)
arithmetic_operators.c 
#include <stdio.h>

int main() {
    int a = 10;
    int b = 3;

    printf("Addition:       10 + 3 = %d\n", a + b);
    printf("Subtraction:    10 - 3 = %d\n", a - b);
    printf("Multiplication: 10 * 3 = %d\n", a * b);
    printf("Division:       10 / 3 = %d\n", a / b);
    printf("Modulus:        10 %% 3 = %d\n", a % b);

    return 0;
}
Terminal Output:
Addition: 10 + 3 = 13 Subtraction: 10 - 3 = 7 Multiplication: 10 * 3 = 30 Division: 10 / 3 = 3 Modulus: 10 % 3 = 1

2. Relational Operators (Comparisons)

Relational operators compare two values. In C, a comparison produces 1 for TRUE and 0 for FALSE.

relational_operators.c 
#include <stdio.h>

int main() {
    int x = 20;
    int y = 10;

    printf("Is x > y?  %d\n", x > y);
    printf("Is x < y?  %d\n", x < y);
    printf("Is x == y? %d\n", x == y);
    printf("Is x != y? %d\n", x != y);

    return 0;
}
Terminal Output:
Is x > y? 1 Is x < y? 0 Is x == y? 0 Is x != y? 1

3. Logical Operators

Combine multiple conditions together: && (AND), || (OR), and ! (NOT).

logical_operators.c 
#include <stdio.h>

int main() {
    int age = 20;
    int hasId = 1;

    if (age >= 18 && hasId == 1) {
        printf("Access Granted!\n");
    }

    return 0;
}
Terminal Output:
Access Granted!
Module 06

Selection: if, if...else, Ladder & Nested if

Decision statements control which path of code executes based on whether a condition is true or false.

1. The Simple if Statement (One Path)

Executes code only if the condition evaluates to true.

if_example.c 
#include <stdio.h>

int main() {
    int marks = 65;

    if (marks >= 35) {
        printf("Congratulations! You passed.\n");
    }

    return 0;
}

2. The if...else Statement (Two Paths)

Analogy — A Fork in the Road:
If you are 18 or older (age >= 18), you take the "Eligible to Vote" path. Otherwise, you must take the "Too Young" path. You can never take both paths at the same time.
if_else_example.c 
#include <stdio.h>

int main() {
    int age = 19;

    if (age >= 18) {
        printf("You are eligible to vote!\n");
    } else {
        printf("You are too young to vote.\n");
    }

    return 0;
}
Terminal Output:
You are eligible to vote!

3. The else if Ladder (Multiple Choices)

Use chained conditions when evaluating more than two possible outcomes.

else_if_ladder.c 
#include <stdio.h>

int main() {
    int num = 0;

    if (num > 0) {
        printf("The number is positive.\n");
    } else if (num < 0) {
        printf("The number is negative.\n");
    } else {
        printf("The number is zero.\n");
    }

    return 0;
}
Terminal Output:
The number is zero.

4. Nested if Statements (Condition Inside Condition)

Analogy — Security Checkpoints:
To enter the secure lab, you first swipe your main building card (Outer if). Only if you are inside the building can you enter your PIN code at the inner door (Inner if).
nested_if_demo.c 
#include <stdio.h>

int main() {
    int marks = 82;

    if (marks >= 35) {
        printf("Result: Passed!\n");

        if (marks >= 75) {
            printf("Honors: Distinction!\n");
        } else {
            printf("Honors: Regular Pass.\n");
        }
    } else {
        printf("Result: Failed.\n");
    }

    return 0;
}
Terminal Output:
Result: Passed! Honors: Distinction!
Module 07

The switch Statement

A switch statement tests a single variable against a list of constant values (case). The break keyword exits the switch immediately, and default runs if no match is found.

switch_demo.c 
#include <stdio.h>

int main() {
    int day = 2;

    switch(day) {
        case 1:
            printf("Monday\n");
            break;
        case 2:
            printf("Tuesday\n");
            break;
        case 3:
            printf("Wednesday\n");
            break;
        default:
            printf("Other day\n");
    }
    return 0;
}
Terminal Output:
Tuesday
Module 08

Iterative Statements: for, while, do...while & Nested Loops

A loop repeatedly executes a block of code while a condition remains true.

1. The for Loop (Count-Controlled)

Best when you know in advance how many times the loop should run.

for_loop.c 
#include <stdio.h>

int main() {
    for (int i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
Terminal Output:
1 2 3 4 5

2. The while Loop (Entry-Controlled)

Evaluates the condition before running the body.

while_loop.c 
#include <stdio.h>

int main() {
    int count = 3;
    while (count > 0) {
        printf("%d... ", count);
        count--;
    }
    printf("Go!\n");
    return 0;
}
Terminal Output:
3... 2... 1... Go!

3. The do...while Loop (Exit-Controlled)

Unlike while, a do...while loop executes its body at least once before evaluating the condition at the bottom.

do_while_loop.c 
#include <stdio.h>

int main() {
    int k = 1;
    do {
        printf("Step %d\n", k);
        k++;
    } while (k <= 3);

    return 0;
}
Terminal Output:
Step 1 Step 2 Step 3

4. Nested Loops (Loop Inside Loop)

Nested loops are ideal for working with grids, patterns, and matrices.

nested_loops_pattern.c 
#include <stdio.h>

int main() {
    for (int row = 1; row <= 3; row++) {
        for (int col = 1; col <= 3; col++) {
            printf("* ");
        }
        printf("\n");
    }
    return 0;
}
Terminal Output:
* * * * * * * * *
Module 09

Jump Statements: break & continue

Jump statements alter the natural sequential flow of execution inside loops and switches.

  • break: Immediately terminates and exits the loop entirely.
  • continue: Skips the remaining code in the current iteration and jumps to the next iteration.
jump_statements.c 
#include <stdio.h>

int main() {
    printf("Testing continue (skips 3):\n");
    for (int i = 1; i <= 5; i++) {
        if (i == 3) continue;
        printf("%d ", i);
    }

    printf("\nTesting break (stops at 3):\n");
    for (int i = 1; i <= 5; i++) {
        if (i == 3) break;
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
Terminal Output:
Testing continue (skips 3): 1 2 4 5 Testing break (stops at 3): 1 2
Module 10

1-D Arrays (Single Dimension)

An array is a collection of elements of the same data type stored at contiguous memory locations. In C, array indexes start at 0.

array_1d_demo.c 
#include <stdio.h>

int main() {
    int marks[5] = {80, 75, 90, 85, 70};

    for (int i = 0; i < 5; i++) {
        printf("Student %d: %d marks\n", i + 1, marks[i]);
    }

    return 0;
}
Terminal Output:
Student 1: 80 marks Student 2: 75 marks Student 3: 90 marks Student 4: 85 marks Student 5: 70 marks
Module 11

2-D Arrays (Matrices)

A 2-D array organizes elements into rows and columns, making it the standard representation for mathematical matrices.

matrix_2d.c 
#include <stdio.h>

int main() {
    int matrix[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    for (int r = 0; r < 2; r++) {
        for (int c = 0; c < 3; c++) {
            printf("%d\t", matrix[r][c]);
        }
        printf("\n");
    }

    return 0;
}
Terminal Output:
1 2 3 4 5 6
Module 12

Searching in Arrays: Linear & Binary Search

Searching is the process of locating a specific target value inside an array.

1. Linear Search (Sequential Check)

Checks every element one by one from left to right. Works on any array.

linear_search.c 
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int target = 30;
    int found = -1;

    for (int i = 0; i < 5; i++) {
        if (arr[i] == target) {
            found = i;
            break;
        }
    }

    if (found != -1) {
        printf("Element %d found at index %d\n", target, found);
    } else {
        printf("Element not found\n");
    }
    return 0;
}
Terminal Output:
Element 30 found at index 2

2. Binary Search (Divide & Conquer)

Requires a sorted array. It repeatedly compares the target against the middle element, eliminating half of the remaining elements at each step.

binary_search.c 
#include <stdio.h>

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int low = 0, high = 4, target = 40, index = -1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target) {
            index = mid;
            break;
        } else if (arr[mid] < target) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }

    printf("Target %d found at index %d\n", target, index);
    return 0;
}
Terminal Output:
Target 40 found at index 3
Module 13

Strings in C

C does not have a native string data type. Instead, a string is stored as an array of characters ending with a special null terminator character: '\0'.

strings_demo.c 
#include <stdio.h>

int main() {
    char platformName[] = "LearnForge";

    printf("Welcome to: %s\n", platformName);
    printf("First letter: %c\n", platformName[0]);

    return 0;
}
Terminal Output:
Welcome to: LearnForge First letter: L
Module 14

Functions in C

A function is a reusable block of code designed to perform a specific task. Instead of writing the same lines of code repeatedly, you define it once in a function and call it whenever needed.

The Kitchen Machine Analogy:
Think of a function like a kitchen appliance:
  • Parameters (Inputs): The raw ingredients dropped into the machine.
  • Return Value (Output): What the machine outputs back to you.
  • void: Means "empty" or "nothing". When used as a return type, the function performs an action and returns no value.

The 4 Types of Functions in C

Every function in C falls into one of four categories based on parameters and return values:

Type 1: Without Parameters and Without Return Value

Takes no data from main() and returns no result.

type1_no_param_no_return.c 
#include <stdio.h>

void greet() {
    printf("Welcome to LearnForge C Course!\n");
}

int main() {
    greet();
    return 0;
}
Terminal Output:
Welcome to LearnForge C Course!

Type 2: Without Parameters and With Return Value

Takes no input, but calculates or retrieves a value and returns it.

type2_no_param_with_return.c 
#include <stdio.h>

int getPassMark() {
    int pass = 35;
    return pass;
}

int main() {
    int scoreNeeded = getPassMark();
    printf("Minimum passing mark is: %d\n", scoreNeeded);
    return 0;
}
Terminal Output:
Minimum passing mark is: 35

Type 3: With Parameters and Without Return Value

Receives data to work on, performs an operation, and prints the result directly.

type3_with_param_no_return.c 
#include <stdio.h>

void printSquare(int num) {
    int square = num * num;
    printf("The square of %d is: %d\n", num, square);
}

int main() {
    printSquare(6);
    return 0;
}
Terminal Output:
The square of 6 is: 36

Type 4: With Parameters and With Return Value

Receives input values, computes a result, and sends the answer back to the caller.

type4_with_param_with_return.c 
#include <stdio.h>

int addNumbers(int a, int b) {
    return a + b;
}

int main() {
    int total = addNumbers(10, 25);
    printf("Result of addition: %d\n", total);
    return 0;
}
Terminal Output:
Result of addition: 35

Module 16

Introduction to Pointers

A pointer is a variable that stores the memory address of another variable.

  • & (Address-of operator): Retrieves the memory address of a variable.
  • * (Dereference operator): Accesses the value stored at that memory address.
pointer_intro.c 
#include <stdio.h>

int main() {
    int age = 20;
    int *ptr = &age;

    printf("Value of age: %d\n", age);
    printf("Value via *ptr: %d\n", *ptr);

    *ptr = 25;
    printf("New value of age: %d\n", age);

    return 0;
}
Terminal Output:
Value of age: 20 Value via *ptr: 20 New value of age: 25
