CH-36 Hard

Binary Search Implementation

Implement Binary Search on a sorted array `{11, 22, 33, 44, 55, 66}` to locate target `44` using `low`, `high`, and `mid` pointers.

💡 Show Hint
`mid = low + (high - low) / 2`. If `target > arr[mid]`, `low = mid + 1`; else `high = mid - 1`.
💻 Show Code Solution
search_ch3.c
#include <stdio.h>

int main() {
    int arr[6] = {11, 22, 33, 44, 55, 66};
    int target = 44, low = 0, high = 5, ans = -1;

    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target) { ans = mid; break; }
        else if (arr[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    printf("Binary Search: Target %d found at index %d\n", target, ans);
    return 0;
}
Terminal Output:
Binary Search: Target 44 found at index 3

CH-48 Hard

Swap Two Numbers (Call by Reference)

Write a function `void swap(int *a, int *b)` that swaps two integers in `main()` using their pointers and a temporary variable.

💡 Show Hint
Pass memory addresses with `swap(&x, &y)` and dereference inside `swap`.
💻 Show Code Solution
ptr_ch3.c
#include <stdio.h>

void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    printf("Before: x=%d, y=%d\n", x, y);
    swap(&x, &y);
    printf("After:  x=%d, y=%d\n", x, y);
    return 0;
}
Terminal Output:
Before: x=10, y=20 After: x=20, y=10
